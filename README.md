# 🧪 Programs Overview

🔹 Small Programs

- F_to_C.py
  
  - Converts temperature from Fahrenheit to Celsius

- Star pyramid.py
  
  - Prints pyramid star pattern

- Reverse pyramid.py
  
  - Prints inverted pyramid pattern

---

🚀 Mini Projects

- CreditChecker.py
  
  - Checks eligibility based on conditions (basic finance logic)

- Crud_pandas.py
  
  - Perform Create, Read, Update, Delete using pandas

- Fake_new.py
  
  - Simple fake news detection logic (basic project)

- SpendsTracker.py
  
  - Tracks daily expenses

- StudentQr_generator.py
  
  - Generates QR code for student details

- StudentRecord.py
  
  - Stores and manages student records using files
